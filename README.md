# Kambaz — Learning Management System (Frontend)

A responsive frontend web application for a course management platform, built with Next.js, React, TypeScript, and Redux. Features dynamic routing, component-based architecture, and state management.

## Features

- Course navigation and dashboard
- Dynamic routing with Next.js App Router
- Global state management with Redux
- Responsive UI with React Bootstrap
- RESTful API integration with backend services
- Deployed live on Vercel

## Tech Stack

Next.js · React · TypeScript · Redux · Bootstrap · CSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
